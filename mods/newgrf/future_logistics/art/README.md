# Art sources

Concept art and requirements from the Corporate Infrastructure handoff (Gareth, 24 October 2026),
kept as delivered. None of it is used in the NewGRF yet; see the NewGRF README, "Art", for what
it needs before use.

| File | Shows |
|---|---|
| `originals/rocket_idle.png` | Rocket, no exhaust |
| `originals/rocket_powered.png` | Rocket with exhaust (body differs in size from the idle rocket) |
| `originals/spaceport_empty.webp` | Spaceport without rocket (lossy WebP) |
| `originals/spaceport_occupied.webp` | Spaceport with rocket (not identical to the empty one outside the rocket) |
| `originals/drone_port.webp` | Four-pad drone port |
| `originals/cargo_drone.webp` | Quadcopter cargo drone, one view |
| `originals/distribution_centre.webp` | Four-bay distribution centre with solar roof |
| `originals/data_centre.webp` | Data centre tower and service buildings |
| `Corporate_Infrastructure_NewGRF_Handoff.md` | The requirements handoff; its parameters (costs, sizes, years, capacities) were not provided |

An earlier `corporate_infrastructure_newgrf_source_v0_1.zip` defined six decorative objects from
older versions of this art. It compiles with NML 0.9.0 and loads, but every building is one
image on one tile with no colour masks, so it was not imported.
